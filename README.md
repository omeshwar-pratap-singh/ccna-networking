## What You Will Find Here

### Notes
This repository includes **progressive, structured notes** aligned with the **CCNA 200-301 syllabus**.

- Initial topics contain **handwritten notes**, created during early learning to build core understanding.
- As the journey progresses, notes transition into **clean digital format** with:
  - Clear CLI command examples
  - Network topology diagrams
  - Well-labeled images for better visualization

This progression reflects natural learning growth and helps clarify concepts that are often confusing when learned only through text.

### Labs
Hands-on labs created using **Cisco Packet Tracer**, focused on:
- Cisco IOS CLI configuration
- Verification using `show` commands
- Troubleshooting and traffic flow analysis
- Realistic networking scenarios

---

## How to Use This Repository Effectively

1. **Start with Notes**  
   Read the relevant topic from the `01_Notes.pdf` first.

2. **Move to Labs Immediately**  
   After finishing a topic, open the matching lab in `00_Labs`.

3. **Configure Before Copying**  
   Try commands yourself before referring to any saved configs.

4. **Verify and Troubleshoot**  
   Use `show` commands and connectivity tests to understand behavior.

5. **Repeat Until Clear**  
   Redo labs until you can explain *why* each command is used.

This **notes → lab → verification** flow is intentional and mirrors real-world networking practice.
